WHY I BUILT THIS

A small tool, born from family trips.

I created Timestamp Cleaner to remove the camera timestamps from my own family videos recorded during trips. It began as a Python script. Today, a native Rust interface makes it easier to choose an area, compare a repair, and export a single result.

— Nir Rozen, project creator

All releases, including betas ↗
Download SHA256SUMS.txt ↗

  1. Choose setup EXE or portable ZIP. Setup installs for your user and adds a versioned Start shortcut and uninstall entry. For a ZIP, extract the entire archive and keep its files together. Older releases may offer only a ZIP.
  2. Check the download before running it. Compare Get-FileHash .\<downloaded-file> -Algorithm SHA256 in PowerShell against SHA256SUMS.txt. Read the included START-HERE.md and the setup guide.
  3. Install the Microsoft runtime if missing. Use the official Visual C++ v14 Redistributable (x64).
  4. Launch from Start or the extracted folder. The app detects FFmpeg and FFprobe. If missing, it offers installation through WinGet with your consent. If setup fails, follow the manual media-tool guide.
  5. Try a short video. Select the timestamp, render a preview, choose MKV or MP4, and export. Play the result to check picture and audio.

An early beta, built in the open.

The current Windows beta is unsigned. Exact-package desktop testing, clean-machine installation and recovery, executable branding, and artifact-specific dependency-notice review remain outstanding. Read the release notes before testing.

The current repair uses FFmpeg rectangle interpolation. It cannot reconstruct the original pixels hidden by a timestamp. Rotated, HDR, alpha and non-square-pixel inputs are unsupported. See the README for input and stream-preservation limits.
